SMS Gateway API

Send SMS against a partner wallet. Authenticate with a JWT issued to an API User. Pricing follows the SMS profile attached to that partner. Each accepted message writes a consumption transaction and deducts credit.

1Create an API user

In Users, create an account and assign the role API_USER. Partner administrators can do this for their organisation. Back-office administrators must also select the partner the user belongs to.

  • The user must be active and linked to a partner.
  • Use that username and password only for API access.
  • Any other role calling SMS/sendSMS receives UNAUTHORIZED USER.

4Pricing and credit

Cost uses the SMS pricing profile currently attached to the partner. PER_SEGMENT bills each segment; otherwise one SMS is one unit. Credit is checked before send, deducted only after a successful provider response, and a CONSUMPTION transaction is stored for every accepted message.

  • Insufficient wallet balance returns an error before any message is sent.
  • Failed recipients are not charged.
  • The response includes cost, transactionId, balanceAfter, and the profile used.

6Return codes

returnCode Meaning
0 Success, or a partial send where at least one recipient was accepted
1 The provider rejected every recipient
401 Missing or invalid JWT — AUTHENTICATION REQUIRED
403 The caller is not an active API_USER — UNAUTHORIZED USER
500 Validation or processing error. returnMessage has the detail, for example insufficient credit.
